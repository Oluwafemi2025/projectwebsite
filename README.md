## School Management Portal

A modern, user-friendly School Management Portal designed to streamline academic and administrative processes for students and lecturers. The platform features secure authentication, dedicated dashboards, and a responsive interface for seamless navigation between user roles.

#Features

**Student Portal**

* Secure authentication and personalized dashboard
* School fee and hostel payment management
* Semester course registration system
* Profile and personal information management
* Academic results viewing and tracking

**Lecturer Portal**

* Customizable dashboard interface
* Course management with resource link integration
* Academic resource sharing and management
* Discussion forum for collaboration
* Attendance management with filtering options
* Exportable attendance reports (CSV)
* Dashboard analytics for courses and student performance
* Secure logout with session redirection

##Overview

The system improves digital learning experiences by simplifying academic workflows and enhancing interaction between students, lecturers, and institutional management through a clean and responsive web interface.

###Technologies Used:
HTML, CSS, JavaScript, jQuery, JSON
