# projectwebsite
Designed and developed a modern, user-friendly School Management Portal that streamlines academic and administrative activities for both students and lecturers through dedicated dashboards and secure authentication systems.
The platform features a responsive landing homepage with an intuitive navigation structure, introducing users to the institution while providing quick access to Student and Lecturer portals through organized dropdown navigation menus. Each portal includes a secure login system with guided authentication prompts for seamless access.
Key Features
Student Portal
Secure student authentication and personalized dashboard
School fee and hostel payment integration with payment information forms
Semester course registration system
Profile and personal information management
Academic result viewing and tracking
Lecturer Portal
Advanced dashboard with customizable interface themes/colors
Course management with integrated textbook resource links
Ability to add and manage academic resource links
Built-in discussion forum for academic collaboration
Attendance management system with course, semester, and date selection
Exportable attendance reports in CSV format
Dashboard analytics displaying assigned courses and top-performing students
Secure logout functionality with homepage redirection
The project focuses on improving digital learning experiences, simplifying academic workflows, and enhancing interaction between students, lecturers, and institutional management through a clean and professional web interface.
Technologies Used: HTML, CSS, JavaScript,JQuery and JSON.
